# FisioLife — Profissional Full V4

Demonstração independente da FisioLife Centro Terapêutico Multiprofissional, em Parnaíba-PI.

## O que foi integrado nesta fase

- logo e favicon oficiais;
- conteúdo público real do site e Instagram da clínica;
- Encontre seu Cuidado sem diagnóstico;
- diretório e busca de profissionais;
- busca global do site;
- FisioLife em Movimento com Reels oficiais;
- tour da estrutura;
- PWA instalável com manifest + service worker;
- mapa interativo MapLibre + OpenStreetMap;
- preferências de privacidade / métricas opcionais;
- tour guiado da experiência;
- smooth scroll respeitando redução de movimento;
- WhatsApp contextual;
- base pronta para agenda online real quando a clínica fornecer a URL oficial;
- experiência mobile refinada.

## Open source pesquisado/aproveitado

- Radix UI
- React Hook Form + Zod
- Embla Carousel
- Lucide
- MapLibre GL JS
- Driver.js
- Lenis
- padrões de Umami/PostHog para analytics com privacidade
- padrões de PWA/offline
