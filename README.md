# FisioLife — Profissional Full V3

Demonstração independente de redesign da FisioLife Centro Terapêutico Multiprofissional, em Parnaíba-PI.

## Evoluções desta versão

- logo e favicon oficiais da FisioLife;
- fachada e profissionais reais publicados pela clínica;
- hero premium com marca oficial;
- busca inteligente global;
- busca fuzzy de profissionais com Fuse.js;
- navegação “Encontre seu cuidado” sem diagnóstico;
- neurodesenvolvimento em jornada própria;
- tour da clínica e conteúdo oficial do Instagram;
- FisioLife em Movimento com Reels oficiais;
- carrossel editorial;
- modal de vídeo;
- mapa, primeira visita e WhatsApp contextual;
- motion/smooth scrolling respeitando prefers-reduced-motion;
- mobile refinado;
- acessibilidade e avisos clínicos.

## Componentes/projetos GitHub estudados ou aproveitados

- krisk/Fuse — busca fuzzy;
- darkroomengineering/lenis — smooth scroll;
- davidjerleke/embla-carousel — referência para navegação/carrossel;
- radix-ui/primitives — referência de padrões acessíveis para dialogs;
- lucide-icons/lucide — referência de iconografia;
- dimsemenov/PhotoSwipe — referência de experiência para mídia/lightbox.
